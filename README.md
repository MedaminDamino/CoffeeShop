# Coffee Shop Project

This is a full-stack coffee shop application consisting of a Laravel backend (coffee-app) and a Vue.js frontend (coffee-frontend).

## Features

- User authentication and authorization
- Product management
- Order processing
- Reservations
- Admin panel for managing branches, categories, products, etc.

## Setup

### Backend (Laravel)
1. Navigate to `coffee-app` directory
2. Run `composer install`
3. Copy `.env.example` to `.env` and configure
4. Run `php artisan migrate`
5. Run `php artisan serve`

### Frontend (Vue.js)
1. Navigate to `coffee-frontend` directory
2. Run `npm install`
3. Run `npm run dev`

## Technologies Used

- Backend: Laravel, PHP, SQLite
- Frontend: Vue.js, TypeScript, Tailwind CSS
